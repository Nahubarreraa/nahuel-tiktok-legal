Cómo crear el token
  1. Entrá a github.com → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repositorio: solo nahuel-tiktok-legal.
  3. Permisos de repositorio: Actions: Read and write e Issues: Read and write.
  4. Copiá el token y pegalo arriba.
